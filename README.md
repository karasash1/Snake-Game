# Snake Game
A classic Game built with python and **turtle** library, designed with custom Gif graphics for the Snake head and the body segments, provided by three live speed buttons, score, high score tracking.
## Features
- **Speed Levels:** Can switch speed at any time while playing between **Easy**, **Midium**, and **Hard** using the on-screen buttons.
- **Score & High Score:** Tracks your current score and best score during the Game.
- **Game Over Reset:** Display a Game Over message, after the head of the snake hits the walls or the snake body, and Resets the board score, and keep the high score.
- **Good GIF:** The game provided by gifs to make the snake shape better than the inserted squares by python.
## Controles
- **Move Up:** ( W )key or (Up Arrow)
- **Move Down:** ( S )key or (Down Arrow)
- **Move Right:** ( D )key or (Right Arrow)
- **Move Left:** ( A )key or (Left Arrow)
- **change speed:** Click the **Easy**, **Medium**, or **Hard** buttons at the bottom of the screen.
